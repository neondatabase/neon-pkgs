Add `@neon/auth`, migrated from `neondatabase/neon-js` (previously published as `@neondatabase/auth`) — Supabase-compatible and Better Auth adapters for Neon Auth, with React, Next.js, and a framework-agnostic server toolkit (`@neon/auth/server`; see `BUILDING-AN-ADAPTER.md`). Versioning continues from the last `@neondatabase/auth` release.

The deprecated `react/ui` / `ui/*` compatibility re-exports for `@neondatabase/auth-ui` and the `neon-auth-codemod` bin are not carried over onto the new package name — install and import from `@neondatabase/auth-ui` directly.
