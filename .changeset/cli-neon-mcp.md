Add `neon mcp` to install the Neon MCP server into coding agents. A TTY asks scope (global default), agents, API key vs OAuth, then confirms. Linked project-folder installs also ask whether to pin tools to that project. `-y` is global, detected agents, minted write API key. `--read-only`, `--project-id` and `--category` set MCP URL query params.
