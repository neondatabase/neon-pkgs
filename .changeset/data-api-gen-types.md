Add `neon data-api gen-types`, which generates TypeScript types from a database schema. It replaces `neon-js gen-types`: `--db-url` is now optional (the CLI resolves the project, branch, role and database like `connection-string`), the output file is `--out-file` instead of `--output`, and `--query-timeout` is now applied. `--out-file -` writes to stdout. The database connection verifies the server certificate for `sslmode=require`, `verify-ca` and `verify-full`, honors `sslrootcert` and `channel_binding=require`, and skips verification only for `sslmode=no-verify`. `--db-url` falls back to `DATABASE_URL`, unless `--project-id`, `--branch`, `--database` or `--role-name` is passed. `--schema` defaults to the schemas the Data API exposes for the branch (`public` with a connection string or when the Data API is not enabled). `sslmode=prefer` encrypts without verifying and retries in plaintext if the server has no TLS, `sslmode=allow` uses plaintext, `ssl=true|false` map to `require|disable`, and `sslcert`/`sslkey`/`sslca` are rejected. Connecting times out after 10s and queries after 30s by default.
