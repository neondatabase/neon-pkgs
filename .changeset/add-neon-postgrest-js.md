Add `@neon/postgrest-js`, migrated from `neondatabase/neon-js` (previously published as `@neondatabase/postgrest-js`) — a generic PostgreSQL client for the Neon Data API with no authentication dependency. Versioning continues from the last `@neondatabase/postgrest-js` release. For auth-integrated clients, pair it with `@neon/auth` or supply your own token via `fetchWithToken`.
