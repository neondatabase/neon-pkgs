`neon mcp`, `neon skills`, and `neon init` support Factory Droid, fx, Hermes Agent, Junie, Kilo Code, Kimi Code, Kiro CLI, and Pi. `neon plugins` installs the Neon plugin into Kimi Code at user level. fx installs only with `--oauth`. GitHub Copilot CLI project installs now write `.mcp.json`, or `.github/mcp.json` when only that file exists, instead of `.vscode/mcp.json`.
