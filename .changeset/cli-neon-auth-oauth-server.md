Add `neon neon-auth config oauth-server get|update` to configure the Neon Auth OAuth 2.1 authorization server (including MCP support, which `--no-mcp` removes), `neon neon-auth config oauth-server resource list|add|remove` to manage its protected resources incrementally, and `neon neon-auth oauth-client list|create|get|update|delete|rotate-secret` to manage its OAuth clients.
